03 / MLOPS AISLADO

Actualizar, evaluar y conservar.

Descarga horaria. Reentrenamiento semanal con al menos 168 horas objetivo nuevas. Las revisiones de una misma hora no cuentan como datos nuevos.

Un candidato posterior solo se activa si reduce al menos un 1 % el MAE del modelo activo, supera o iguala repetir el último valor y no empeora el RMSE. Ambos modelos se comparan en el mismo periodo nuevo.

Si no supera los controles, se conserva el modelo activo. Se guarda la versión anterior para restaurarla desde el flujo autorizado de GitHub Actions.
